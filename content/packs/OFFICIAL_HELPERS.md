# 0.19.0 官方協助者對照

來源：本機企劃 `docs/card-data/卡片06-協助者.md`、`docs/3D專案企劃/06-協助者與羈絆規格.md` 與已確認的 G 系列時序裁定。自定義協助者未載入。

| ID | 卡面角色 | 觸發時機／共用機制 |
|---|---|---|
| 01 | 流浪道具商人 | 持續：道具、裝備費用 -1，最低 0 |
| 02 | 流浪道具商人 | 休息清理後、抽牌前：可將棄牌堆道具放牌庫頂 |
| 03 | 公會櫃台小姐 | 購買開始：公開個人牌庫頂，連續取得敵卡，首張非敵卡留頂 |
| 04 | 公會櫃台小姐 | 購買開始：本回合擊敗敵人時，按目前隊員數取得購買力 |
| 05 | 酒吧老闆 | 回合開始：可取回棄牌堆冒險者，每回合一次 |
| 06 | 酒吧老闆 | 持續：冒險者費用 -1，最低 0 |
| 07 | 謎之少女 | 持續：休息抽牌數改為 6 |
| 08 | 謎之少女 | 持續：隊伍上限 6；離場按座位收斂最右側超額隊員與裝備 |
| 09 | 武器舖店主 | 持續：裝備費用 -1，最低 0 |
| 10 | 武器舖店主 | 休息清理後、抽牌前：可將棄牌堆裝備放牌庫頂 |
| 11 | 情報商 | 回合開始：強制將一張手牌交給左側玩家；無手牌直接完成 |
| 12 | 情報商 | 進／離場：選官方冒險者或物資牌庫，公開最多玩家數張並依座位輪抽 |

每種各 1 張，共 12 張；本局從中抽出與 Boss 數相同的協助者，僅公開 1 張。Boss 擊敗與其他輪替來源共用 `HelperService.rotate`。正式來源／公開輪抽／牌庫／已離場區均為 Zone；選擇、跨玩家 required actor 與轉移使用可序列化 pending choice。首次登場以起始玩家控制，最後 Boss 擊敗仍結算舊協助者離場，之後不再揭示新卡。
